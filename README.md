# منفذ خريطة

نظام ويب لإدارة حجوزات وبيع كتب المرحلة الثانوية.

## الموجود في النسخة الأولى
- تسجيل دخول لحسابي محمد نبيه وعلي جبله.
- إنشاء فاتورة/حجز مختصر.
- إضافة ملاحظة للفاتورة.
- أكثر من كتاب داخل الفاتورة.
- حساب الإجمالي تلقائيًا.
- رقم حجز تلقائي.
- حفظ أسماء المدرسين والكتب تلقائيًا.
- بحث فوري جزئي بالاسم/الهاتف/رقم الفاتورة/المدرس.
- حالات: محجوز، تم التسليم، ملغي.
- طباعة وصل.
- سجل عمليات.
- قاعدة بيانات SQLite محلية.

## الجديد في هذا التحديث
- **بيانات كل موظف خاصة به**: كل حساب (غير المدير) يرى ويدير حجوزاته هو فقط، ولا يرى بيانات الموظفين الآخرين.
- **حساب المدير**: حساب "محمد نبيه" أصبح صلاحيته "مدير" ويمكنه عرض بيانات كل الموظفين (مع فلتر لاختيار موظف معيّن) وإدارة سلة المهملات بالكامل.
- **📦 الأرشيف**: صفحة منفصلة تعرض فقط العناصر المؤرشفة، مع إمكانية البحث فيها واسترجاعها لمكانها الأصلي في أي وقت.
- **⚙️ الإعدادات → 🗑️ سلة المهملات**: أي فاتورة تُحذف تُنقل هنا أولًا (لا تُحذف نهائيًا). يمكن استرجاعها لمكانها الأصلي، أو حذفها نهائيًا بشكل فردي، مع تأكيد قبل كل حذف نهائي.
- **محو سلة المهملات**: صلاحية إدارية فقط (المدير)، ويتطلب تأكيدًا إضافيًا (كتابة كلمة "تأكيد")، لأنه الإجراء الوحيد الذي لا يمكن التراجع عنه.
- **⚙️ الإعدادات → محو جميع البيانات**: بدل الحذف المباشر من قاعدة البيانات، يتم نقل كل حجوزات الموظف الحالية إلى سلة المهملات، فلو حصل ضغط بالغلط يقدر يسترجعها من هناك.
- **سجل العمليات**: زر حذف بجانب كل عملية لحذفها من السجل، وزر "مسح السجل بالكامل" (للمدير فقط).
- **وضع داكن / فاتح**: زر تبديل المظهر أعلى الصفحة، ويُحفظ الاختيار في المتصفح.
